\# FitLog — Workout Library

FitLog is a responsive workout library web application where users can browse workouts, view detailed exercise information, add workouts to today's plan, save workouts for later, and track completed exercises.

## Technologies

- Next.js
- React
- App Router
- Tailwind CSS
- Lucide React
- Sonner
- REST API

## Features

1. Responsive workout library for mobile, tablet, and desktop.
2. Browse 12 workouts with images, categories, equipment, duration, calories, and ratings.
3. Sort workouts by duration, calories, or rating.
4. View detailed workout information including description, specifications, and instructions.
5. Add workouts to Today's Plan with a maximum of five lifts.
6. Save workouts for later and manage saved workouts.
7. Track workout completion with Mark as Done.
8. View live exercise, minutes, and calorie metrics in My Plan.
9. Toast notifications for important workout actions.
10. Custom 404 page for invalid routes.
